# Deep-Learning-Study
딥러닝의 핵심 이론을 학습하고, Python과 TensorFlow/Keras를 활용한 실습 코드 및 실험 결과를 기록하는 저장소입니다.

## 주요 학습 교재(Textbook)
- 교재명: 파이썬으로 배우는 인공지능
- 저자: 오일석, 이진선
- 출판사: 한빛아카데미

## 학습 개요
기계학습의 기초 이론과 실습을 학습한 이후, 딥러닝에 대한 이해를 심화하기 위해 본 저장소를 개설하였습니다.
교재의 4장(신경망 기초)부터 학습 내용을 기록하며, 교재에서 다루는 핵심 개념뿐만 아니라 학습 과정에서 발생한 궁금증, 추가 탐구 내용, Python 실습 코드 및 실험 결과를 정리합니다.
