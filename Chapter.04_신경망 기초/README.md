
# Chapter 04. 신경망 기초

## 퍼셉트론(Perceptron)

- 퍼셉트론은 입력층과 출력층으로 구성된 기본적인 인공신경망이다.
- 각 입력값에 가중치를 곱한 후 바이어스를 더하여 가중합을 계산한다.
- 계산된 가중합에 활성 함수를 적용하여 최종 출력을 결정한다.

$$
o = \tau(s) = \tau\left(\sum_{i=1}^{d}w_ix_i+w_0x_0\right)
$$

- $x_i$ : 입력 특징
- $w_i$ : 입력에 대한 가중치
- $w_0x_0$ : 바이어스 항 ($x_0=1$)
- $\tau$ : 활성 함수

### 활성 함수

- 퍼셉트론은 계단 함수를 이용하여 입력의 가중합에 따라 출력을 결정한다.

$$
\tau(s) =
\begin{cases}
+1, & s>0 \\
-1, & s<0
\end{cases}
$$

## 퍼셉트론 학습 알고리즘

- 퍼셉트론의 학습 목표는 훈련 데이터를 올바르게 분류하도록 가중치를 조정하는 것이다.
- 잘못 분류한 샘플을 기준으로 손실 함수를 계산하고, 손실이 감소하는 방향으로 가중치를 수정한다.

### 손실 함수

$$
J(w)=\sum_{x\in I}-y(wx^T)
$$

- $I$ : 잘못 분류한 샘플의 집합
- $y$ : 정답 레이블
- 모든 샘플을 정확히 분류하면 $J(w)=0$이 된다.

### 가중치 갱신

- 경사하강법은 손실 함수의 기울기 반대 방향으로 가중치를 갱신하는 방법이다.

$$
w\leftarrow w-\rho\nabla J(w)
$$

- 퍼셉트론의 손실 함수를 적용하면 다음과 같은 가중치 갱신 규칙을 얻는다.

$$
w\leftarrow w+\rho\sum_{x\in I}yx
$$

- $\rho$ : 학습률
- 가중치 갱신과 분류 과정을 반복하여 오분류를 줄인다.

## 단층 퍼셉트론의 한계

- 단층 퍼셉트론은 선형 결정 경계를 이용하여 데이터를 분류한다.
- 선형 분리가 불가능한 데이터는 완벽하게 분류할 수 없다.
- 대표적인 예시로 XOR 문제가 있다.

## 다층 퍼셉트론(MLP)

- 다층 퍼셉트론(Multi-Layer Perceptron)은 여러 퍼셉트론을 층별로 연결한 인공신경망이다.
- 입력층, 하나 이상의 은닉층, 출력층으로 구성된다.
- 은닉층에서는 입력 데이터의 특징을 변환하며, 비선형 활성 함수를 통해 복잡한 분류 경계를 표현할 수 있다.
- 따라서 단층 퍼셉트론이 해결하지 못하는 XOR과 같은 비선형 분류 문제를 해결할 수 있다.

## 경사하강법의 학습 방식

- **배치 모드(Batch)** : 전체 훈련 데이터를 이용하여 가중치를 갱신한다.
- **패턴 모드(Pattern)** : 훈련 샘플 하나마다 가중치를 갱신한다.
- **미니배치 모드(Mini-Batch)** : 일부 훈련 샘플을 묶어 가중치를 갱신한다.
- **SGD** : 무작위로 선택하거나 섞은 데이터를 이용하여 기울기를 추정하고 가중치를 갱신한다.
